# 星际探险家 - 宇宙科普小程序

面向6-12岁小学生的宇宙科普微信小程序，使用 UniApp + Vue3 + TypeScript 开发。

## 功能

- 八大行星知识卡片系统（图文+语音介绍）
- 行星收集家（问答解锁卡片）
- 火箭发射挑战（倒计时答题）
- 成就徽章系统（22个徽章）
- 积分与等级体系
- 家长学习报告

## 技术栈

- UniApp + Vue3 + TypeScript
- 本地静态数据
- Web Speech API / 微信TTS 语音朗读
